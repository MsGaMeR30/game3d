# 🎯 NEON VANGUARD

A fast-paced, arcade-style 3D First-Person Shooter (FPS) arena game that runs directly in the browser with zero dependencies or build steps required. Built using **Three.js** for 3D rendering and the **Web Audio API** for procedural sound synthesis.

🔗 **[Play Live Demo Here](https://msgamer30.github.io/game3d/)** 

---

## ✨ Features

* **Full 3D Movement & Physics:** Smooth directional movement, sprinting with dynamic FOV zoom and thruster stamina management, jumping, ramps, elevated platforms, and high-velocity Cyber Jump Pads.
* **Three Distinct Weapons:**
  * **1 — Pulse Rifle:** Balanced, rapid-fire energy rifle for mid-range combat.
  * **2 — Ion Scatter Shotgun:** High-spread burst weapon designed for close-quarters swarm clearing.
  * **3 — Rail Lance:** High-damage precision beam weapon for taking down heavy targets at long range.
* **Wave-Based Enemy AI:**
  * **Stalker Drones:** Standard pursuit units that close the distance quickly.
  * **Swarm Seekers:** Agile, fast-moving aerial units that attack in groups.
  * **Heavy Gunship Bots:** Armored aerial threats that fire dodgeable plasma projectiles.
* **Tactical HUD & Audio:** Live mini-map radar, floating enemy health bars, armor repair drops, particle explosions, and procedural Web Audio API sound effects (no external audio assets needed).

## 🎮 Controls

| Input | Action |
| :--- | :--- |
| **W, A, S, D** / **Arrow Keys** | Move |
| **Mouse** | Look / Aim |
| **Left Click** | Shoot |
| **Spacebar** | Jump |
| **Left Shift** | Sprint (Consumes Thruster Stamina) |
| **1, 2, 3** | Switch Weapons (Pulse Rifle / Shotgun / Rail Lance) |
| **R** | Reload Weapon |
| **ESC** or **P** | Pause Game / Release Mouse Cursor |
